# 🤖 AI College Helpdesk Chatbot

## 📌 Project Description
AI College Helpdesk Chatbot is a simple Python-based chatbot that answers common questions related to a college. It provides quick information about admission, fees, exams, results, library, hostel, placements, courses, contact details, principal timings, and college timings.

## ✨ Features
- Admission Information
- Fee Details
- Exam Information
- Result Information
- Library Timings
- Hostel Information
- Placement Details
- Course Information
- Contact Details
- Principal Meeting Time
- College Timings
- Current Date
- Exit using "bye"

## 🛠 Technologies Used
- Python 3

## ▶️ How to Run
1. Install Python 3.
2. Open the project folder.
3. Run the following command:

```bash
python app.py
```
